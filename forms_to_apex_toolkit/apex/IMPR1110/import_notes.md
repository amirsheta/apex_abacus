## 3. Placeholders

The script has `set define off`. Four tokens, each appearing twice (header comment + `component_begin`):

| Token | Value | How to get it |
|---|---|---|
| `__WORKSPACE_ID__` | workspace id | `SELECT workspace_id FROM apex_workspaces WHERE workspace = '<NAME>';` |
| `__APP_ID__` | id of the application installed from f345 | App Builder, or `SELECT application_id FROM apex_applications WHERE application_name = '<NAME>';` |
| `__SCHEMA_NAME__` | parsing schema (f345: `CUSTOMS`) | `SELECT owner FROM apex_applications WHERE application_id = <APP_ID>;` |
| `__ID_OFFSET__` | ID offset of the installed application (f345 value: `64111868204433090374`) | `SELECT template_id - 11621850520475869674 FROM apex_application_temp_page WHERE application_id = <APP> AND template_name = 'Standard';` |

**The offset must match.** Every template, the user interface, the page 0 toolbar region and the
*Page Functions* list are referenced as `wwv_flow_api.id(<f345 number>)`. Those IDs resolve only if
`__ID_OFFSET__` equals the offset of the installed application. Do **not** import with
`apex_application_install.generate_offset`.

Check before the import: `grep -n '__[A-Z_]*__' apex/IMPR1110/f345_impr1110.sql` must list only the
four tokens, and `grep -n '{{' apex/IMPR1110/f345_impr1110.sql` must print nothing.
