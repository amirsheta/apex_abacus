> **Block notes**
> - `TITLE`, `EDI_MSG`, `LSIDE`, `TOOLBAR` are OLB control blocks (screen frame). They are replaced by the f345 page template, the page 0 toolbar and the `FUNCS` region.
> - `IMPR_PRTL_NAT` (first navigation block, multi-record, 5 shown / 8 buffered) has the fixed WHERE `REVIEW_FLAG = 0 AND GAZT_NAME IS NOT NULL` and no ORDER BY: it lists the portal rows still waiting for review. `InsertAllowed=false`, `DeleteAllowed=false`, Update / Query at the default (true). All items except `REVIEW_FLAG` have `UpdateAllowed=false`, so the only change the user can make is the review status. After saving, the row stays on screen until the next query (it then no longer matches the WHERE).
> - The block's PRE-INSERT / PRE-UPDATE / PRE-DELETE triggers write the activity log `ACTIVITY.ADD_ACTIVITY(9, 8, 1 / 2 / 3, PRTL_NAT_ISN)`; PRE-INSERT and PRE-DELETE can never fire (insert / delete not allowed) but are kept in the trace.
> - `IMPORTERS` (multi-record, 10 shown / 13 buffered) is **query only** (Insert / Update / Delete false). There is no `<Relation>`: the WHERE clause binds `:impr_prtl_nat.impr_type_cd`, `ctry_cd`, `bus_id_type_cd`, `bus_id` and `NVL(bus_id_brnch, 0)`, and `IMPR_PRTL_NAT.WHEN-NEW-RECORD-INSTANCE` runs `GO_BLOCK('IMPORTERS')` + `CLEAR_BLOCK` + `EXECUTE_QUERY` + `GO_BLOCK('IMPR_PRTL_NAT')` (messages suppressed, errors ignored). So the grid shows the importers already registered with the same identification as the portal row, across all ports (no port filter).
