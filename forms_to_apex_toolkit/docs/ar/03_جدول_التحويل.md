# جدول التحويل المرجعي — Forms 12c إلى APEX 21.2

## 1. أنواع الكائنات
| كائن Forms | المقابل في APEX 21.2 |
|---|---|
| ملف الشاشة (.fmb) | صفحة أو أكثر داخل تطبيق |
| ملف القائمة (.mmb) | قائمة التنقل (Navigation Menu)، والصلاحيات من صلاحيات التطبيق (بدون Authorization Schemes) |
| مكتبة PL/SQL (.pll) | حزمة في قاعدة البيانات `LIB_<name>` |
| مكتبة الكائنات (.olb) / Property Class | Theme وTemplate Options وShared Components |
| Data Block بسجل واحد | منطقة Form مع Form Initialization وAutomatic Row Processing |
| Data Block متعدد السجلات قابل للتعديل | Interactive Grid قابل للتعديل |
| Data Block للقراءة فقط | Interactive Report أو Classic Report |
| Control Block | منطقة Static Content تحتوي حقول الصفحة |
| علاقة Master-Detail | صفحة Master-Detail، أو خاصية "Master Region" في IG |
| حقل نصي أو للعرض | Text Field / Number Field / Date Picker / Display Only |
| قائمة / Radio / Checkbox | Select List / Radio Group / Switch أو Checkbox |
| زر | Button |
| صورة | Display Image / File Browse |
| Canvas عادي / Stacked / Tab | صفحة / Inline أو Modal Dialog / Tabs Container أو Region Display Selector |
| نافذة Modal | صفحة Modal Dialog |
| LOV + Record Group (استعلام ثابت) | Shared LOV أو Popup LOV أو Select List |
| Record Group (وقت التشغيل) | `APEX_COLLECTION` |
| التنبيه (Alert) | Confirm DA أو `apex.message.confirm` أو خطأ تحقق أو رسالة نجاح |
| Visual Attribute | CSS Class أو Template Option أو تمييز في IG |
| Parameter | حقل صفحة يُمرَّر عبر الرابط |
| Program Unit | إجراء أو دالة داخل حزمة |
| Timer | `setInterval` في JavaScript + DA، أو Scheduler Job |

## 2. الدوال المدمجة (Built-ins)
| دالة Forms | البديل في APEX 21.2 |
|---|---|
| `MESSAGE` | رسالة نجاح العملية؛ `apex.message.showPageSuccess` |
| `SHOW_ALERT` | Confirm DA / `apex.message.confirm` / `apex.message.alert` |
| `RAISE FORM_TRIGGER_FAILURE` | `raise_application_error` / `apex_error.add_error` |
| `GO_BLOCK`، `GO_ITEM` | DA من نوع Set Focus؛ `apex.item('P1_X').setFocus()` |
| `GO_RECORD`، `NEXT_RECORD`، `FIRST_RECORD` | التنقل في IG؛ أزرار التنقل في منطقة Form |
| `EXECUTE_QUERY` | DA لتحديث المنطقة (Refresh) أو إرسال الصفحة |
| `ENTER_QUERY` | البحث في IR/IG أو Faceted Search أو حقول فلترة |
| `COMMIT_FORM` | Submit + Automatic Row Processing (يتم الـ commit تلقائياً في نهاية الطلب) |
| `ROLLBACK` / `CLEAR_FORM` | زر إلغاء + Branch مع Clear Cache |
| `CLEAR_BLOCK`، `CLEAR_ITEM` | DA من نوع Clear؛ Clear Cache للحقول أو المنطقة |
| `SET_ITEM_PROPERTY` (إظهار/تفعيل/إلزامي) | DA للإظهار والإخفاء والتفعيل؛ شروط من جهة السيرفر؛ تحققات |
| `SET_BLOCK_PROPERTY(DEFAULT_WHERE/ORDER_BY)` | استعلام المنطقة مع ربط حقول الصفحة (Binds) |
| `GET_ITEM_PROPERTY`، `NAME_IN` | `:P1_ITEM` أو `v('P1_ITEM')` أو `apex_util.get_session_state` |
| `COPY` | `apex_util.set_session_state`؛ DA من نوع Set Value |
| `CALL_FORM`، `OPEN_FORM`، `NEW_FORM` | Branch أو رابط أو Modal Dialog؛ `apex_page.get_url` |
| `CREATE_GROUP`، `POPULATE_GROUP`، `ADD_GROUP_ROW` | `apex_collection.create_collection_from_query_b` و`add_member` |
| `GET_GROUP_CHAR_CELL` وما يشبهها | `SELECT c001.. FROM apex_collections` |
| `HOST` | Job في `DBMS_SCHEDULER` |
| `WEB.SHOW_DOCUMENT` | تحويل أو رابط؛ `apex_util.redirect_url` |
| `TEXT_IO` / `CLIENT_TEXT_IO` | File Browse + `apex_application_temp_files`؛ `UTL_FILE`؛ التنزيل عبر process |
| `RUN_REPORT_OBJECT` | BI Publisher / Report Query / APEX Office Print / PL/PDF |
| `DO_KEY` | استدعاء الـ process أو الـ DA المكافئ |
| `SYNCHRONIZE`، `SET_APPLICATION_PROPERTY(CURSOR_STYLE)` | غير مطلوب / `apex.util.showSpinner` |
| `GET_APPLICATION_PROPERTY(USERNAME)` | `:APP_USER` |

## 3. الـ Triggers
| Trigger في Forms | المقابل في APEX 21.2 |
|---|---|
| PRE-FORM، WHEN-NEW-FORM-INSTANCE | Process أو Computation في مرحلة Before Header |
| WHEN-NEW-BLOCK/RECORD/ITEM-INSTANCE | DA (تحميل الصفحة، تغيّر التحديد في IG، Get Focus) |
| WHEN-VALIDATE-ITEM | تحقق على الحقل (+ DA عند التغيير لإظهار النتيجة فوراً إن لزم) |
| WHEN-VALIDATE-RECORD | تحقق على الصفحة أو على صف IG |
| WHEN-CREATE-RECORD | القيم الافتراضية للحقول؛ القيم الافتراضية لأعمدة IG |
| PRE-QUERY | شرط WHERE في استعلام المنطقة مع Binds |
| POST-QUERY | JOIN أو عمود في View أو دالة في SQL؛ Computation في After Header (لسجل واحد) |
| PRE-INSERT/UPDATE/DELETE | Process قبل Automatic Row Processing (لكل صف في IG) |
| POST-INSERT/UPDATE/DELETE | Process بعد Automatic Row Processing |
| ON-INSERT/UPDATE/DELETE | Process للـ DML بنوع Target Type = PL/SQL Code |
| PRE-COMMIT / POST-FORMS-COMMIT | Processes قبل وبعد عمليات الـ DML |
| ON-LOCK | القفل التفاؤلي (Checksum مدمج) |
| WHEN-BUTTON-PRESSED | زر ← Submit + Process، أو DA عند النقر |
| WHEN-LIST-CHANGED، WHEN-RADIO-CHANGED، WHEN-CHECKBOX-CHANGED | DA من نوع Change |
| KEY-COMMIT، KEY-EXIT، KEY-* | أزرار؛ واختصارات لوحة مفاتيح بـ JS عند الحاجة |
| ON-ERROR، ON-MESSAGE | دالة معالجة الأخطاء على مستوى التطبيق |
| WHEN-TIMER-EXPIRED | مؤقت JS + DA، أو Scheduler Job |
| WHEN-MOUSE-* | DA لأحداث الفأرة، وغالباً يُستغنى عنها |

## 4. متغيرات النظام
| Forms | APEX 21.2 |
|---|---|
| `:SYSTEM.CURRENT_FORM` | `:APP_PAGE_ID`، `:APP_ALIAS` |
| `:SYSTEM.CURSOR_BLOCK/ITEM`، `:SYSTEM.TRIGGER_ITEM` | `this.triggeringElement` في JS داخل الـ DA |
| `:SYSTEM.RECORD_STATUS` | `:APEX$ROW_STATUS` في IG (C/U/D)؛ في Form: المفتاح الأساسي فارغ يعني سجلاً جديداً |
| `:SYSTEM.MODE` (NORMAL/ENTER-QUERY) | لا ينطبق |
| `:SYSTEM.FORM_STATUS`، `BLOCK_STATUS` | `apex.page.isChanged()` في JS |
| `:SYSTEM.CURRENT_DATETIME`، `$$DATE$$` | `SYSDATE` / `LOCALTIMESTAMP` |
| `:SYSTEM.MESSAGE_LEVEL` | لا ينطبق |
| `:SYSTEM.LAST_QUERY` | استعلام المنطقة / واجهات `apex_region` |
| `USER` (في Forms) | `:APP_USER` |
| `:PARAMETER.<name>` | حقل صفحة `P<page>_P_<NAME>`، والشاشة المستدعية تمرّره في Application Item باسم `P_<NAME>` (عملية `PARAMETERS ENTRY`). معاملات القائمة تستخدم حقول f345 (`P_CURR_PORT_CD` و`SSO_APP_USER` وغيرها) |
| `:GLOBAL.<name>` | Application Item باسم `G_<NAME>` (معيار f345) |

## 5. تحويل Record Group إلى APEX Collection
<div dir="ltr">

```sql
-- Forms: rg := CREATE_GROUP_FROM_QUERY('RG_PRICES','SELECT ...'); POPULATE_GROUP(rg);
apex_collection.create_collection_from_query_b(
    p_collection_name => 'COLLECTION_RG_PRICES',
    p_query           => 'SELECT product_id, price FROM prices WHERE active = ''Y''');
-- Forms: GET_GROUP_NUMBER_CELL('RG_PRICES.PRICE', i)
SELECT TO_NUMBER(c002) FROM apex_collections WHERE collection_name = 'COLLECTION_RG_PRICES' AND seq_id = :i;
-- ADD_GROUP_ROW / SET_GROUP_CHAR_CELL -> apex_collection.add_member / update_member_attribute
-- DELETE_GROUP -> apex_collection.delete_collection
```
</div>

- الدالة `create_collection_from_query_b` تخزّن أعمدة الاستعلام في الأعمدة `c001` إلى `c050` كنصوص.
- الـ Collections خاصة بجلسة APEX لكل مستخدم. إذا كانت البيانات مشتركة بين عدة مستخدمين فاستخدم جدولاً حقيقياً.

## 6. المتغيرات العامة (GLOBAL) إلى Application Items
| Forms | APEX |
|---|---|
| `:GLOBAL.company_id := 10;` | Shared Components ← Application Items ← `G_COMPANY_ID` (مع Session State Protection: Restricted). تُضبط القيمة في عملية f345 "After Auth" بعد تسجيل الدخول، أو بـ `FORMS_COMPAT.set_global('COMPANY_ID', 10)` |
| `x := :GLOBAL.company_id;` | `:G_COMPANY_ID` في SQL/PLSQL؛ `FORMS_COMPAT.get_global('COMPANY_ID')` داخل الحزم |
| `ERASE('GLOBAL.x')` | `FORMS_COMPAT.erase_global('X')` (الحقل `G_X`) |
| `DEFAULT_VALUE('x','GLOBAL.y')` | Application Computation (عند بدء جلسة جديدة) |
