### 13.1 Menu

The same as IMPR1110 (inventory rev 2 §13.1): menu `CIC_MENU` does not name the form or pass parameters; the launchers `APPS` / `BUTTON_LAST_TREE` open it with the `P_*` parameters; `SET_MENU_ITEM_PROPERTY` is not used; the in-form menu is the OLB `LSIDE` block filled by `TMPLT.POPULATE_FUNCTIONS`.

### 13.2 Function-level security

| Mechanism | Location | Details |
|---|---|---|
| Load user functions | `NIB.WHEN_NEW_FORM_INSTANCE` (`CIC_LIB.pld`) → `TMPLT.LOAD_FUNCTIONS` | role tables `SC_USER_ROLES`, `SC_GROUP_ROLES`, `SC_SYSOBJ_ROLE_PRIVS`, `SC_USER_EXCLUDED_ROLES` |
| Enable / disable functions | PU `ADJ_FUNS` | **one function only**: `IMPR_MCI_SERVICE`, enabled when `BUS_ID_TYPE_CD = 2 AND ALLOW_MCI = 1` or `IMPR_TYPE_CD = 4 AND BUS_ID_TYPE_CD IN (3,5) AND ALLOW_MOI = 1` |
| Run a function | PU `EXECUTE_FUNCTION` / `EXEC_FUNS` | `EXEC_FUNS('IMPR_MCI_SERVICE')` → `UPDATE_IMPORTER` (names refresh from MCI); other codes go through the generic `EXECUTE_FUNCTION` (SC_SYSTEM_OBJECTS, CALL_FORM / RUN_PRODUCT) |
| Settings | WNFI | `ALLOW_MCI` / `ALLOW_MOI` from `SC_PORT_SETTING` (`SYSOBJ_ID = 24`) |
| Personal importer mode | parameter `PRSNL_IMPR = 1` | WHEN-CREATE-RECORD / PRE-QUERY force `IMPR_TYPE_CD := 4` and lock it |
| Delete permission | `KEY-DELREC` only deletes when the toolbar item `REMOVE` is visible **and** enabled | block delete allowed (default) |
| Data scope | block WHERE `PORT_CD = :PARAMETER.P_CURR_PORT_CD` | row-level restriction by port |

### 13.3 APEX mapping notes (f345 standard – no code in this step)

- **Page access:** the application's existing privileges (CLAUDE.md §8); no authorization schemes are generated.
- **Functions:** the page 0 `FUNCS` drawer with the f345 *Page Functions* list; `ADJ_FUNS` → computation `P1130_ADJ_FUNS` (comma list of enabled codes).
- **Parameters:** `P_*` → f345 application items as in IMPR1110 (§12 notes); `PRSNL_IMPR` / `LETTER_NBR` → page items `P1130_P_PRSNL_IMPR` / `P1130_P_LETTER_NBR`.
- **Port scope:** query filter `PORT_CD = :P_CURR_PORT_CD` (search page and main-page fetch).
- **Delete:** page 0 `DELETE` button with the confirm text of KEY-DELREC; package `KEY_DELREC` runs the dependency check, the child deletes and the delete.
