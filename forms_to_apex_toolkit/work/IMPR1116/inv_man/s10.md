### 10.3 Classification of package-qualified calls (library vs database)

> The library texts in `forms/COMMON/libraries/` were searched for every package the form calls. The frame calls are the same as IMPR1120 §10.3.

| Package / prefix | Origin | Library file / source | Used for (active calls in IMPR1116) |
|---|---|---|---|
| `NIB.*` | Forms library | `CIC_LIB.pld` | form startup, ON-ERROR / ON-MESSAGE, timers, KEY-* handlers, window handling (frame) |
| `STR.*` | Forms library | `CIC_LIB.pld` (→ DB `STR_DB`, **MISSING SOURCE**) | `DispAlert` (2, frame only: EXIT button, EXECUTE_FUNCTION) |
| `TMPLT.*` | Forms library | `CIC_LIB.pld` | `POPULATE_FUNCTIONS`, `KEYB_UP_DOWN`, `ENB_DIS_FUN_BUT`, `FUN_ITEMS` (function menu) |
| `HIJDATE.*` | Forms library → DB | `CIC_LIB.pld` → `HIJDATE_DB` (`plsql/Shared/HIJDATE_DB.*`) | `CUR_HIJ_DATE` (3, title bar date), `VALID_HIJ_DATE` (1, TITLE.SYSTEM_DATE) – frame only |
| `ACTIVITY.*` | Forms library → DB | `CIC_LIB.pld` → `ACTIVITY_DB` (`plsql/Shared/ACTIVITY_DB.*`) | `ADD_ACTIVITY(9, 8, 1 / 2 / 3, PRTL_NAT_ISN)` in IMPR_PRTL_NAT PRE-INSERT / PRE-UPDATE / PRE-DELETE (system 9, subject 8) |
| `KEY_CONTROL.*` | Forms library | `CIC_LIB.pld` | `FOUND_KEY` (TOOLBAR.EXIT1) |
| `REP.*`, `ADJ_PRN.*` | Forms library | `CIC_LIB.pld` | `RUN_PRODUCT` / `ADJ_REPORT_PRINTER` in PU EXECUTE_FUNCTION (function menu) |
| `DES$FORM_ERRORS` | Designer message library | `CIC_AMSG.pld` | error stack / messages |
| `CGTE$*` | Designer table-error library | `OFGTEL`: **MISSING SOURCE** | constraint-violation text in the two block ON-ERROR triggers (generic texts only, no constraint names of this form) |
| `CGHP$*` | Designer help library | `OFGHPL.pld` | MS-Help (obsolete) |

No call to `CGBS$` / `CGBS2$` (no relation) and no call to a database package without source.
