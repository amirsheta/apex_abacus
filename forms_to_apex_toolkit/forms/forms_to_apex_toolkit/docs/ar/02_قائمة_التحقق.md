# قائمة التحقق للترحيل — Oracle Forms 12c إلى APEX 21.2

## 1. قبل الترحيل
### تجهيز البيئة
- [ ] تثبيت APEX 21.2.x في DEV وTEST وPROD (للتحقق: `select version_no from apex_release`)
- [ ] إعداد ORDS، وتوفر Universal Theme 42
- [ ] تنفيذ `scripts/setup_apex_workspace.sql` من الـ DBA (الـ Schema `FORMS_MIGRATION` ومساحة العمل)
- [ ] تثبيت utPLSQL v3 في DEV وTEST
- [ ] إنشاء مستودع Git من هذه الحزمة، وتثبيت Claude Code، ومراجعة `CLAUDE.md`
- [ ] توفر سيرفر Forms 12c Builder لتشغيل `frmf2xml`، وأن يشمل `FORMS_PATH` كل ملفات `.olb/.pll`

### الجرد
- [ ] جمع كل ملفات `.fmb/.pll/.olb/.mmb` في `input/fmb/` (والتأكد أنها نفس نسخ الإنتاج)
- [ ] تشغيل `scripts/convert_forms_to_xml.sh input/fmb ./output` بدون أي فشل
- [ ] تحويل `.pll` إلى نص (`frmcmp_batch module=X.pll module_type=LIBRARY script=YES`)
- [ ] تنفيذ القالب 01 لكل شاشة، وتجميع التعقيد والمخاطر في جدول رئيسي
- [ ] ترحيل المكتبات المشتركة أولاً كحزم `pkg_lib_<name>`
- [ ] تحديد الاعتماد على التقارير (`.rdf`) واختيار أداة التقارير البديلة

### موافقة أصحاب القرار
- [ ] اعتماد النطاق وترتيب أولوية الشاشات وخطة المراحل
- [ ] اعتماد طريقة الدخول والصلاحيات (DB أو LDAP أو SSO)
- [ ] قبول تغيّر الواجهة (واجهة ويب بدلاً من الاعتماد على لوحة المفاتيح في Forms)
- [ ] تسمية مسؤول الأعمال ومختبري UAT لكل شاشة

## 3. بعد الترحيل
- [ ] إيقاف شاشة Forms من القائمة أو السيرفر (مع إبقاء نسخة للقراءة فقط لفترة متفق عليها)
- [ ] إيقاف Forms نهائياً بعد فترة الاعتماد، وأرشفة ملفات `.fmb`
- [ ] تدريب المستخدمين (دليل سريع: مفتاح Forms ← زر APEX) وصفحات المساعدة
- [ ] المراقبة: سجل نشاط APEX و`apex_workspace_activity_log` وسجل الأخطاء عبر دالة معالجة الأخطاء
- [ ] مراجعة أداء الصفحات البطيئة (Debug و`apex_debug`)
- [ ] حفظ نسخة من تصدير تطبيق APEX في Git بعد كل إصدار

## 4. سجل المخاطر
| الخطر | الأثر | المعالجة |
|---|---|---|
| منطق مخفي في `.pll` أو `.olb` لم يُصدَّر | سلوك مفقود | تحويل المكتبات أولاً، وضبط FORMS_PATH، ووسم أي مصدر مفقود بـ MISSING SOURCE |
| `HOST` و`TEXT_IO` وOLE وJava Beans والمؤقتات | لا يوجد بديل مباشر في الويب | إعادة التصميم: DBMS_SCHEDULER وFile Browse ومؤقتات JS، والقرار مبكراً |
| استعلامات POST-QUERY لكل صف | بطء التقارير | تحويلها إلى JOIN أو Views |
| نموذج القفل والحفظ الضمني في Forms | ضياع تعديلات | الاعتماد على القفل التفاؤلي في APEX (Checksum)، ومراجعة ON-LOCK |
| حالة `:GLOBAL` بين الشاشات | بيانات خاطئة بين الصفحات | Application Items ومعاملات صريحة في الرابط |
| المستخدمون معتادون على العمل بلوحة المفاتيح | ضعف القبول | دعم لوحة المفاتيح في IG، والتدريب، وعروض مبكرة |
| ملف تصدير APEX المولّد غير صالح للبيئة | فشل الاستيراد | استخدام تصدير مرجعي، والاستيراد في DEV، والمراجعة اليدوية |
| اقتراح الذكاء الاصطناعي لميزات بعد إصدار 21.2 | كود لا يمكن استيراده | قفل الإصدار في CLAUDE.md، والمراجعة |
| التقارير (`RUN_REPORT_OBJECT`) | مخرجات مفقودة | اختيار BI Publisher أو APEX Office Print أو PL/PDF |
| شاشات كبيرة تتجاوز سعة سياق Claude | تحليل ناقص | شاشة واحدة لكل جلسة، وقراءة XML على أجزاء |
