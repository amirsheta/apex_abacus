### 13.1 Menu

| Property | Value |
|---|---|
| Menu module | `CIC_MENU` (`forms/COMMON/menus/CIC_MENU_MMB.xml`); it does not open IMPR1116. Screens are opened by `APPS` / `BUTTON_LAST_TREE` from `SC_SYSTEM_OBJECTS`; no other form in the repository names IMPR1116 |
| SET_MENU_ITEM_PROPERTY | **not used** |
| In-form "menu" | `LSIDE` side menu (`TMPLT.POPULATE_FUNCTIONS`), `TOOLBAR.FUN_BUT`, `KEY-F9`. `ADJ_FUNS` and `EXEC_FUNS` are empty (`NULL;`) |

### 13.2 Function-level and data security

| Mechanism | Location | Details |
|---|---|---|
| Screen access | launcher / privileges | no check in the form itself (no `CURRENT_SIDE`, no port check) |
| Port scope | – | **none**: neither block filters on `P_CURR_PORT_CD`; every user who opens the screen sees and reviews the rows of all ports |
| Update permission | ON-ERROR (FRM-40509 / ORA-01031 texts in the frame) | DB grants; only `REVIEW_FLAG` can be changed |
| Function menu | PU EXECUTE_FUNCTION | `SC_SYSTEM_OBJECTS`, `SC_PORT_SETTING`, role tables through `TMPLT` / `KEY_CONTROL` |

### 13.3 APEX mapping notes (f345 standard; no code in this step)

- **Page access:** the application's existing privileges (CLAUDE.md §8); no authorization schemes are generated.
- **Port scope:** none, as in Forms (§15 #4 asks whether that is intended).
- **Functions:** f345 *Page Functions* list in region `FUNCS`.
