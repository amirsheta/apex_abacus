# IMPR1210 – Inventory & Migration Risk Assessment

- **Form:** IMPR1210 (module `IMPR1210`, title "صيانة تفاويض الشركات الوسيطة", window title `Agnts`): maintenance of the authorizations an importer gives to a broker company (شركة وسيطة) in the user's port – table `AGNTS`. The clerk enters a new authorization (importer, broker company, use import / export, note), changes a valid one, and cancels / restores an authorization through the two side-menu functions.
- **Source:** `forms/IMPR/IMPR1210_fmb.xml` (frmf2xml output)
- **Target:** Oracle APEX 21.2 on Oracle Database 12.1.0.2, reference application f345 (CLAUDE.md §4b, §4c)
- **Produced:** 2026-11-25 (step 01): mechanical sections by `scripts/gen_inv.py`; manual analysis in sections 1, 13–15 (sources in `work/IMPR1210/inv_man/`). Frame comparison with IMPR1170 (cloned from this form): `work/IMPR1210/scripts/cmp_frame.py`.
- **Sources used besides the form XML:** library text `forms/COMMON/libraries/CIC_LIB.pld` (ACTIVITY, INTRFACE.MAKE_BLOCK_FULL_OPERATION, STR, HIJDATE), OLB `forms/COMMON/olb/CIC_OLB_OLB.xml` (item classes `CGSO$CHAR_ARB_DO`, `CGSO$POP_DO`, `CGSO$POP_MD`, `CGSO$RADIO_MD`, `CGSO$HDATE_ARB_DO`), LOV forms `forms/COMMON/lov_forms/LOV_IMPR_fmb.xml`, `LOV_AGNT_ATHR_IMPR_fmb.xml`, `LOV_SD_PORTS_fmb.xml`; the IMPR1150 / IMPR1160 / IMPR1170 inventories for the shared OLB frame findings.
- **Scope rule:** anything not available is marked **MISSING SOURCE** and is not guessed: the libraries OFGTEL, SEC_LIB, OFGTAB, PICKLIST, POS, SCDLL, VCDLL; DB packages `LIB_USR.IMPR` (`IMPR_SUSPENDED`), `DCLTN` (`IMPR_IMPR_AUTH_USED`), `STR_DB` (`GETARBMSG`, through FORMS_APX); the CG library `Des$Form_errors` / `CGTE$*`; the form `IMP_NEW` opened by the action button; the DDL of `AGNTS` (column types taken from the Forms items).
