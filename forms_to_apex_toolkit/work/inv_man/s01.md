**Result: COMPLEX** (4 metrics reach Complex).

**Justification.** Although the form has a single base-table block and no master–detail relations, it carries 323 triggers and ~8.7k lines of PL/SQL, of which the biggest units (POST-QUERY 382 lines, GET_CR_DATA 401 lines, UPDATE_IMPORTER 166 lines) contain business rules, explicit DB commits and calls to external web services (MCI, GAZT). A large part of the runtime behaviour (timers, session timeout, function menu, alerts, messaging, field enabling) is delegated to the attached libraries and the object library. Their main sources (`CIC_LIB`, the OLB) are now available, so this behaviour is documented (§10.3) instead of guessed; most of it (timers, window and key handling) is replaced by the f345 application, the rest maps to standard APEX features.
