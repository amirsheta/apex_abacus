> **Item notes**
> - Items of the 4 OLB control blocks have no attributes in the form XML; they come from `CIC_OLB_OLB.xml` and are not migrated.
> - `IMPR_PRTL_NAT`: displayed columns are `PRTL_NAT_ISN` (مسلسل), `ID_TYPE_GZT` (نوع السجل, list), `BUS_ID_NEW` (رقم السجل), `GAZT_NAME` (الاسم), `REVIEW_FLAG` (حالة المراجعة, list, default 0). Hidden: `IMPR_TYPE_CD`, `CTRY_CD`, `BUS_ID_TYPE_CD`, `BUS_ID`, `BUS_ID_BRNCH` (the keys used to query `IMPORTERS`), `TIN_NBR`, `DOC_DT`, `ENTRY_DT`, `USER_ID`, `LST_TRAN_DT`, `UPDATE_DT`. Only `REVIEW_FLAG` is updatable (`InsertAllowed=false`, Update default). The table usage marks `USER_ID`, `LST_TRAN_DT`, `UPDATE_DT` as `UPD`, but **no trigger sets them**: either a DB trigger does or they stay unchanged (§15 #2).
> - `ID_TYPE_GZT` (char 7) static values `ZS0001` رقم الهوية, `ZS0002` رقم اقامة, `ZS0003` خليجى, `BUP002` سجل تجارى, `ZS0005` رقم 700; `REVIEW_FLAG` (number 2) static values 0 قيمة ابتدائية, 1 صحيح و تمت المراجعة, 2 غير صحيح (column comment: 0 initial / 1 correct / 2 rejected). Both lists are overwritten at startup by `CGDV$POPULATE_DYNAMIC_LISTS` from `CG_REF_CODES` domains `ID_TYPE_GZT` and `PRTL_NAT_FLAG`.
> - `IMPORTERS`: displayed `PORT_CD` (الجمرك), `IMPR_NBR` (الرقم), `L_IT1_IMPR_TYPE_NAME` (نوع المستورد), `ARBC_IMPR_NAME` (اسم المستورد), `L_BIT_BUS_ID_TYPE_NAME` (مسمى الاستدلالى); hidden `HQ_IMPR_NBR`, `IMPR_TYPE_CD`, `BUS_ID_TYPE_CD`, `BUS_ID`, `BUS_ID_BRNCH`. The two `L_*` names are non-DB items filled by POST-QUERY (`CGFK$QRY_IMPORTERS_IMP_ITIDT_F`, join `IMPR_TYPE_ID_TYPES` / `IMPR_TYPES` / `BUS_ID_TYPES`). `PORT_CD2`, `L_BIT_BUS_ID_TYPE_NAME2` are LOV buttons, hidden in WHEN-NEW-FORM-INSTANCE.
