### 10.7 Object library / subclassed objects

- Object library: **`CIC_OLB.olb`**, available as `forms/COMMON/olb/CIC_OLB_OLB.xml` (revision 2).
- 195 subclassed objects (elements carrying `ParentModule`), the same OLB frame as IMPR1110 (70 IMPORTERS items instead of 78).
- Resolved from the OLB XML: the 9 alerts (§11) and the parameter list (no defaults, §12). The OLB blocks TITLE / EDI_MSG / LSIDE / TOOLBAR are the standard screen frame, replaced by the f345 page template, page 0 toolbar and FUNCS region; their layout is not needed for the migration.

### 10.8 What the main library calls do, and their APEX equivalent (f345 standard)

| Library call | What it does (from `CIC_LIB.pld`) | APEX 21.2 / f345 equivalent |
|---|---|---|
| `INTRFACE.Make_Field_Entrable(item, TRUE / FALSE)` | `SET_ITEM_PROPERTY` ENABLED, NAVIGABLE, INSERT_ALLOWED, UPDATE_ALLOWED all TRUE / FALSE, plus visual attribute `CG$ITEM_ARB` / `CG$DISPLAY_ITEM_ARB` | Item **Read Only** condition calling a BOOLEAN package function, or native Enable / Disable while the user types (f345 standard §9). 181 calls in 9 units; the rules are grouped per item in step 02 |
| `STR.DispAlert(text, type)` | maps the type to an OLB alert (`INFORMATION` / `ERROR` / `SYSTEM_ERROR` → `CFG_*`, `CONFIRM` → `USR_CONFIRM`, `WARNING` → `USR_WARNING_B`), sets the text, shows it, writes `rsk_audit`, returns the button | ERROR / SYSTEM_ERROR → `CHECK_ERROR` / `FORMS_APX.FORM_TRIGGER_FAILURE`; INFORMATION → success message; CONFIRM / WARNING → native Confirm action |
| `STR.DispArbMsg(sys, nbr)` | message text by number from the message table, shown in an alert | package function returning the text (`ARABIC_MESSAGE`) + the same mapping as DispAlert |
| `STR.StrFormat` | calls DB `STR_DB.StrFormat` | call `STR_DB` directly |
| `HIJDATE.Cur_Hij_Date` / `Valid_Hij_Date` | call `HIJDATE_DB` (OUT message, raise / alert on error) | call `HIJDATE_DB` from the package (source in `plsql/Shared`) |
