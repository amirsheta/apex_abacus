### 13.1 Menu and functions

| Property | Value |
|---|---|
| Menu module | `CIC_MENU`; SET_MENU_ITEM_PROPERTY not used |
| In-form "menu" | `LSIDE` side menu / `KEY-F9`: the module functions from `SC_SYSTEM_OBJECTS` (TMPLT). PU `EXECUTE_FUNCTION` (frame) calls `EXEC_FUNS(<SYS_OS_FILE_NAME>)` for the two functions of this form: `CD1_STOPIMPRAUTH` (إيقاف / إلغاء التفويض) and `CD2_REUSEIMPRAUTH` (إسترجاع التفويض). `ADJ_FUNS` is empty (`NULL;`): no function is hidden by the form |

### 13.2 Data security

| Mechanism | Location | Details |
|---|---|---|
| Query scope | block WHERE `AGNTS.PORT_CD = :PARAMETER.P_CURR_PORT_CD` | the clerk sees and changes only the authorizations of the user's port (f345 item `P_CURR_PORT_CD`) |
| Port of a new record | AGNTS.WHEN-CREATE-RECORD | `PORT_CD := P_CURR_PORT_CD` (PORT_CD is never enterable) |
| Change rules | AGNTS.WHEN-NEW-RECORD-INSTANCE (`INTRFACE.MAKE_BLOCK_FULL_OPERATION`) | queried record: update only when status 1 and not used in a declaration; delete never |
| Activity log | PRE-INSERT, PRE-UPDATE, EXEC_FUNS | `ACTIVITY.ADD_ACTIVITY(9, 1, <1 insert / 2 update / 3 cancel / 4 restore>, PORT_CD!ATHRZTN_SEQ_NBR)` → `ACTIVITY_DB` with port, user and work-station parameters |
| Privilege errors | AGNTS.ON-ERROR (ORA-01031 + FRM-40508/9/10) | "ليس لديك صلاحية الادخال / التعديل / الحذف": table grants of the user |

### 13.3 APEX mapping notes

- Page access: the application's existing privileges (CLAUDE.md §8); no authorization schemes. The two functions are
  entries of the f345 *Page Functions* list (module of IMPR1210 in SC_SYSTEM_OBJECTS); who may run them is granted there.
- The ORA-01031 messages are not needed: APEX runs as the parsing schema.
- The functions arrive as the page 0 FUNCS custom events `CD1_STOPIMPRAUTH` / `CD2_REUSEIMPRAUTH` (IMPR1150 pattern).
