### 10.3 Classification of package-qualified calls (library vs database)

> Revision 2: the library texts in `forms/COMMON/libraries/` were searched for every package the form calls.
> "Library file" is the `.pld` that contains the package specification.

| Package / prefix | Origin | Library file / source | Used for (active calls) |
|---|---|---|---|
| `NIB.*` | Forms library | `CIC_LIB.pld` (same text in `CIC_LIB_CNTRL.pld`) | form startup (`PRE_FORM`, `WHEN_NEW_FORM_INSTANCE` 165 lines), `ON_ERROR`, `ON_MESSAGE`, timers (`WHEN_TIMER_EXPIRED`, EDI message ticker), `CHECK_TIMEOUT` (TEXT_IO), 13 `KEY_*` handlers, window handling — see §10.8 |
| `STR.*` | Forms library | `CIC_LIB.pld` | `DispAlert` (77 active calls), `DispArbMsg` (4), `StrFormat` (3) — all user messages |
| `INTRFACE.*` | Forms library | `CIC_LIB.pld` | `Make_Field_Entrable` (201 active calls), `Make_Block_Full_Operation` (3), `Flash_Alert` (1) |
| `TMPLT.*` | Forms library | `CIC_LIB.pld` | function security: `LOAD_FUNCTIONS`, `ENABLE_FUN` / `DISABLE_FUN`, `POPULATE_FUNCTIONS`, `ENB_DIS_FUN_BUT`, `KEYB_UP_DOWN`; package variables `FUN_ITEMS`, `CURSOR_AT`, `USING_KEYB` … |
| `HIJDATE.*` | Forms library → DB | `CIC_LIB.pld`, which calls `HIJDATE_DB` (`plsql/Shared/HIJDATE_DB.*`, owner LIB_USR) | `CUR_HIJ_DATE` (11), `VALID_HIJ_DATE` (3) |
| `ACTIVITY.*` | Forms library → DB | `CIC_LIB.pld`, which calls `ACTIVITY_DB` (`plsql/Shared/ACTIVITY_DB.*`, owner LIB_USR) | `ADD_ACTIVITY` (5): activity log on insert / update / delete / functions |
| `KEY_CONTROL.*` | Forms library | `CIC_LIB.pld` | `FOUND_KEY` (3): checks `SC_USER_ROLES` / `SC_GROUP_ROLES` / `SC_SYSOBJ_ROLE_PRIVS` / `SC_USER_EXCLUDED_ROLES` |
| `REP.*`, `ADJ_PRN.*` | Forms library | `CIC_LIB.pld` | `RUN_PRODUCT` (reports, 2), `ADJ_REPORT_PRINTER` (printer from `REPORT_PRINTERS`, `SC_PORT_SETTING`) |
| `WIN_API_UTILITY`, `WIN_API_SESSION` | Forms library (Windows DLL) | `D2KWUTIL.pld` | active window, session (client OS) |
| `SEC_DLL` | Forms library (Windows DLL) | `CAPTION.pld` | window caption |
| `DES$FORM_ERRORS` | Designer message library | `CIC_AMSG.pld` | error stack / constraint messages |
| `CGTE$*` | Designer table-error library | `OFGTEL` – **MISSING SOURCE** | constraint-violation message text (IMPORTERS.ON-ERROR) |
| `CGHP$*` | Designer help library | `OFGHPL.pld` | MS-Help (obsolete) |
| `GNRL`, `LIB_USR.GNRL` | Database package | **MISSING SOURCE** | `GET_CUSTOMS_SETTING`, `GET_SEQUENCE_VALUE`, `GET_CUSTOMS_SEQ` |
| `IMPR`, `LIB_USR.IMPR` | Database package | **MISSING SOURCE** | `CHECK_DUPLICATE_IMP_BRKR`, `CHK_MOBILE_FORMAT`, `IMPR_SUSPENDED` |
| `IMPR_UTILITIES`, `LIB_USR.IMPR_UTILITIES` | Database package | **MISSING SOURCE** | `UPDATE_IMPR_MOBILE_NO`, `UPDATE_IMPORTERS_NAMES` |
| `LIB_USR.IMPR_CENTRAL` | Database package | **MISSING SOURCE** | `CREATE_UNI_IMPR_NEBRAS` (PRE-INSERT) |
| `MCISERVICE` | Database package (web-service wrapper) | **MISSING SOURCE** | `GETMAINCRINFOCALL` / `GETBRANCHCRINFOCALL` (Ministry of Commerce CR data) |
| `LIB_USR.WEB_SERVICES_GAZT` | Database package (web-service wrapper) | **MISSING SOURCE** | `PR_IMPORT_IMPR_CERTIFICATE` |
| `DB_JOURNAL`, `STR_DB`, `MSG_FOR_USER`, `ERR_DB` | Database packages | **MISSING SOURCE** | journaling on/off, `StrFormat` (via `STR`), messages |
| `CG$IMPR1110_PROD_CENTRL_GLOBAL` | Form program unit (package spec) | in the XML (§9) | `IMPORTERS_WHERE` variable |
