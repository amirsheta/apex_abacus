### 13.2 Function-level security (in the form's code and the library)

| Mechanism | Location | Details |
|---|---|---|
| Load user functions | WHEN-NEW-FORM-INSTANCE → `TMPLT.LOAD_FUNCTIONS(:PARAMETER.P_USER_ID, :PARAMETER.P_MODULE_ID)` | fills `TMPLT.FUN_ITEMS` from the role tables (`CIC_LIB.pld`) |
| Allowed function? | `KEY_CONTROL.FOUND_KEY` | `SC_USER_ROLES`, `SC_GROUP_ROLES`, `SC_SYSOBJ_ROLE_PRIVS`, `SC_USER_EXCLUDED_ROLES` |
| Enable / disable functions | PU `ADJ_FUNS` (`TMPLT.ENABLE_FUN / DISABLE_FUN`) | function codes `IMPR1110F1`–`IMPR1110F5`, `IMPR1110SF6`, `IMPR_MCI_SERVICE`, `CREATE_BRKR_IMPR_AUTH`, `IMPR1115_GZT`, `IMPR1110_MOB`; reads `SC_USER_ROLES`; sets/reads `:GLOBAL.ALLOW_MCI`, `:GLOBAL.ALLOW_MOI` |
| Run a function | PU `EXECUTE_FUNCTION` / `EXEC_FUNS` | reads `SC_SYSTEM_OBJECTS`, `SC_PORT_SETTING`; CALL_FORM of a dynamic form or `REP.RUN_PRODUCT` |
| User class / type checks | WNFI (`P_CLASS_CD=1 AND P_USER_TYPE=3` → `BROKER_INT`), WHEN-NEW-RECORD-INSTANCE (`P_CLASS_CD=19 AND P_USER_TYPE=1` → force `IMPR_TYPE_CD:=19` + COMMIT), `IMPR_EXPR_TYPE` enabling | 11 units contain user/role checks |
| Delete permission | `KEY-DELREC` only deletes when item `REMOVE` is visible **and** enabled (set by function security) | block `DeleteAllowed=false` |
| Data scope | block WHERE `PORT_CD = :PARAMETER.P_CURR_PORT_CD` | row-level restriction by port |

### 13.3 APEX mapping notes (f345 standard - no code in this step)

- **Page access:** the application's existing privileges (CLAUDE.md §8): no authorization schemes are generated.
- **Functions:** the f345 list *Page Functions* in region `FUNCS` (same role tables as `KEY_CONTROL.FOUND_KEY`); `TMPLT.ENABLE_FUN / DISABLE_FUN` → the list's `P<page>_ADJ_FUNS` filter.
- **Parameters:** `P_*` → f345 application items (`SSO_APP_USER`, `P_CURR_PORT_CD`, `P_CLASS_CD`, `V_USR_TYPE` …, §12 notes), filled by the f345 `After Auth` process.
- **Port scope:** query filter `PORT_CD = :P_CURR_PORT_CD`.
- **Delete:** page 0 `DELETE` button; the policy question in §15 #6 decides whether it is shown.
